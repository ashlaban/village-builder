# VB-168: A pawn's other acts as commands: walk, go home, idle
Status: done (2026-11-02)
Priority: 2
Size: M
Arch: core
Phase: implement
Design ref: Commands, time steps and views (Unified commands: Decided); answers to VB-076 (first verbs `work(job)`, `walkTo(tile)`, `goHome`, `idle(until)`).
Goal: After VB-167 the planner chooses work through commands, but it still moves pawns directly when they have nothing to do: `idleAbout` walks them to company, the green or the yard and sets `idleUntil`, and the day's end sends them home (`goHome`). Make these commands too, so that every act of a pawn goes through `issue`. Depends on VB-167.
Acceptance criteria:
- [x] Verbs `walkTo` (target a tile; args the spot `x`, `y` in map units, defaulting to the tile's centre), `goHome` and `idle` (args `until`, a game time) in `src/sim/commands.js`, each checked (a tile on land that the walking rule allows, `walkable(w)`; an actor with a home; a time not before now).
- [x] `idleAbout` issues `walkTo` and `idle` from source `planner`; going home at dark issues `goHome`. Outside `src/sim/commands.js` and `src/sim/agents.js` nothing calls `walkTo`, `goHome` or `start`, checked statically by the test of VB-167.
- [x] `tests/commands.js` covers each verb and its refusals.
- [x] Behaviour unchanged: `tests/golden.json` unchanged; `npm run verify` passes.
