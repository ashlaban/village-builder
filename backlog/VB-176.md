Goal: Modules import only modules loaded before them, but lookups inside functions reach later ones and make cycles. Kim's rule: the only lookup into a later module is `issue` (and the verbs' own `later()` in `sim/commands`). After VB-175, one such lookup is left besides `issue`: `expansion.js:17`, where plots are started only for those with no farm to claim, while `sim/farmclaims` asks `sim/expansion` who has a plot. Remove it, and check the rule. Depends on VB-175.
