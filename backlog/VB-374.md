# VB-374: A bundler in place of build.py
Status: blocked
Waits for: Kim
Priority: 3
Size: S
Arch: yardstick
Phase: implement
Design ref: none (code structure). `docs/typescript-plan.md` (P2); the survey in `backlog/VB-055.md`.
Goal: `build.py` inlines every file of `src/manifest.json` as its own `<script>` and splices `src/page/*.js` into a closure in `body.html`. Replace it with `build.js` (Node, so one language): one dev dependency, esbuild at an exact version, bundling an entry `src/main.js` that imports the manifest's modules in the manifest's order, for their effects (the `VB` namespace is still how they meet), into one IIFE inlined in `index.html`, with the page script spliced as now. `index.html` stays one self-contained file (PixiJS and the fonts still come from the network), `--check` is kept, and the build id (a hash of the page's sources) is kept.
Acceptance criteria:
- [ ] `node build.js` writes `index.html`; `node build.js --check` fails if it is stale; `build.py` is deleted; `package.json` has the dependency at an exact version and a `build` script; `tests/run.js`, `.github/workflows/checks.yml`, `AGENTS.md` and `BACKLOG.md` name the new command.
- [ ] The built page behaves as before: `tests/smoke.js`, `tests/browser.js` and the other page scripts of `npm run verify` pass, and `tests/golden.js` is unchanged. Not required: a byte-identical `index.html` (the wrapper changes).
- [ ] A build is deterministic: two builds in two directories give the same bytes, and the build id is a function of the sources alone (as VB-214 has it).
- [ ] The size of `index.html` and the build time before and after are in the task file (before: 1,226,620 bytes, `python3 build.py --check` 0.06 s on 12 November). Source maps are not shipped.
- [ ] The task file says whether esbuild's output keeps the `// @sys` comment lines the module map greps (`grep -rn "^// @sys" src` reads `src/`, not the page, so it should not matter).
- 12 Nov 2026 (orchestrator, from VB-055's plan, `docs/typescript-plan.md`, where this task is P2): waits for Kim's answers to `QUESTIONS.md`, "VB-055: the move to TypeScript" (the formatter, the bundler, the hook, the width measures, when, the page and the tests, `strict`), which may change its criteria; the three rules common to these tasks are at the top of the plan.
- May run beside: any task; it touches the build, `package.json`, the workflow and `index.html`, which every task regenerates, so a rebase takes the generated file.
