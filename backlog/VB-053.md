# VB-053: Refactor: page script into modules under lint
Status: ready
Priority: 2
Size: L
Arch: tooling
Phase: implement
Design ref: none (code structure)
Goal: `src/body.html` is the largest source file (about 1,600 lines; its input section alone is 640) and lies outside the module system, the structure lint (`@sys`, 400 lines, 160 characters) and the `@sys` module map. Move its script into modules so the same rules and tools cover it. Depends on VB-025 (a real-browser check, so a broken page is caught); if it is not done, mark this blocked.
Acceptance criteria:
- [ ] The page script moves verbatim, by its `// ----` sections, into `src/page/<section>.js` modules registered as `VB['page/<section>']`, each with an `@sys` header and under 400 lines. State the sections share (`app`, `w`, `st`, the layers, `speed`) lives in `VB['page/state']`, read and written through it.
- [ ] `src/manifest.json` lists the page modules after the simulation modules; `build.py` inlines them; `src/load.js` (Node) still loads only the simulation modules.
- [ ] `src/body.html` keeps the markup, the styles and a short start-up script.
- [ ] `tests/lint.js` checks the page modules like the others.
- [ ] Refactor rules hold; also the VB-025 browser check passes.
