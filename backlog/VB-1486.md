# VB-1486: Check: every theme defines every token
Status: ready
Priority: 2
Size: S
Design ref: Kim, 22 November; VB-1161
Goal: A theme that misses a token fails npm test.
Acceptance criteria:
- [ ] A fast check (`tests/themes.js`, a line in `tests/suites.js`, fast tier) reads the stylesheet through `readSource` and the themes from `src/page/options.js`: every key of `THEMES` has a token block, every block's key is in `THEMES`, and every block sets every theme token of the list VB-1484 wrote.
- [ ] A token used by the base (`var(--x)`) that no theme sets and the base does not define fails the check, named.
- [ ] The check fails on a constructed stylesheet missing one token (the check's own self-test), and passes on the repository.
- [ ] `npm test` stays within its ten seconds; `npm run verify` green.

## Notes

Builds on VB-1484's token list.
