# VB-055: Type checking of the JavaScript with checkJs
Status: needs-review
Priority: 3
Size: M
Arch: tooling
Phase: implement
Design ref: none (test infrastructure)
Goal: A misspelt field (`hh.grian`) or a wrong argument is silent in plain JavaScript until it misbehaves. The TypeScript compiler can check plain JavaScript (`checkJs`) with JSDoc types, without changing the code to TypeScript or adding a build step.
Acceptance criteria (proposed):
- [ ] `typescript` as a dev dependency; `tsconfig.json` with `allowJs`, `checkJs`, `noEmit`, over `src/**/*.js`.
- [ ] `src/types.d.ts` declares the `VB` namespace's modules and the shapes of `st`, `w`, pawns, households, farmsteads, villages and jobs, taken from the `@state` tags.
- [ ] `npm test` runs `tsc -p .` and fails on errors; today's errors, if any, are fixed or listed in a baseline that may only shrink (like `tests/lint-baseline.json`).
- [ ] Once VB-053 is done, the page modules are checked too.
Notes / questions:
- Needs Kim's approval for a new dev dependency (`typescript`, about 25 MB installed).
- Alternative or addition: ESLint with `no-undef` and `no-unused-vars`, also a dev dependency.
