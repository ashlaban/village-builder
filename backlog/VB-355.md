# VB-355: The player sows: verbs for a field's rotation, and crops on the map
Status: ready
Priority: 1
Size: M
Arch: crops
Phase: implement
Design ref: Goods and the farming year, Crops and rotations (design.md, section 8)
Goal: Parity of command for crops, and what the player sees of them. The player chooses freely: the other heads' short choice is for cost (Kim, 11 Nov).
Acceptance criteria:
- [ ] Verbs in `src/sim/commands.js`: set a field's rotation (any rotation of the rules the household has seed for, not only the village's usual one) and sow one field out of turn for a year; each checks the seed, the window and that the field is free, and returns why not; only the holder may issue them. The holder's own rule goes through the same verbs with `source: 'pawn'`; `tests/commands.js` holds.
- [ ] A field's tile info names its crop, its course, its soil, what is sown next and the seed held of each crop, and is where the played head reaches the verbs. Nothing is added to the Plan tab, which is to be removed (Kim, 18 Nov; VB-1123, whose walk W4 is this choice in plan mode).
- [ ] The page draws each crop at each stage (rye green in autumn and under snow in winter, peas, tilled fallow), reading `st` only; screenshots by `tools/shot.js` in the PR.
- [ ] With no player command a run is unchanged (`node tools/same.js --base REF` prints `same`). `npm run verify` (it touches `src/page/`).
Cost: none in a run without a player.
