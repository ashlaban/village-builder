# VB-062: Mood and its modifiers, shown in the pawn panel
Status: ready
Priority: 2
Size: M
Arch: social
Phase: implement
Design ref: none yet (new, Kim, 2026-10-30). Kim: the pawn info screen shows active modifiers, for example "mood +5, recently talked to a friend".
Goal: Give each pawn a mood built from modifiers with a value, a label and an end time, so events in a pawn's life show up as feelings. In this first version mood has no effect on behaviour; it is shown, and later tasks may read it.
Acceptance criteria:
- [ ] `p.mods`: a list of `{ key, label, value, until }` (`until` in game hours, or null while a condition lasts); `p.mood` = 50 + the sum of the values, clamped to 0..100. `@state` documented.
- [ ] `addMod(st, p, key, value, days, label)` adds or refreshes a modifier with the same key; expired modifiers are dropped once a game day.
- [ ] Starting modifiers (values to tune later): talked with a friend +5 for 2 days (VB-061); newly married +10 for 12 days; a child born +5 for 12 days (both parents); grieving −15 for 12 days when a spouse, child or parent dies; hungry −20 × h while hunger h > 0.1; weak −10 while health is below 50 (once VB-050 is done).
- [ ] The pawn panel shows mood (a number and a word: miserable, low, content, happy) and each active modifier with its sign, value and label.
- [ ] Mood has no effect on any decision in this task.
- [ ] A test: each starting modifier appears on its trigger and expires on time.
- [ ] Re-record the golden file and list the changed entries in the PR.
Notes / questions:
- Later: mood could weigh in courting, quarrels and leaving; decide in the courting plan (VB-036).
