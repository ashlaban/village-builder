# VB-099: Worn paths between farms, well and woods
Status: needs-review
Priority: 3
Size: M
Design ref: Systems overview (Presentation: Worn paths, missing (new): lanes appear between farms, well and woods over years; one counter per tile, repainted with the chunk). Proposed.
Goal: Pawns walk the same ways every day for decades, and nothing on the map shows it. Desire paths would make a village's habits visible: the lane to the well, the track to the commons wood, the path between two farms that intermarry. Depends on VB-025 (a real-browser check catches drawing errors); if it is not done, mark this blocked.
Acceptance criteria (draft, pending `QUESTIONS.md`, VB-099):
- [ ] A footfall counter per tile (`w.wear`, a typed array, `@state` documented) rises by 1 each time a pawn enters the tile and decays once a game day with the answered half-life (proposed 2 years).
- [ ] Tiles above the answered thresholds (proposed: 200 a year a faint track, 1,000 a clear path) are painted with a worn track in the chunk bake; a chunk is repainted at most once a game day, and only when one of its tiles crosses a threshold.
- [ ] Paths have no effect on walking speed in this task.
- [ ] Cost: under 1 ms per game hour on populous medium; repaints spread over frames as the tree-stage repaints are.
- [ ] Re-record the golden file if `w.wear` enters it and list the changed entries in the PR.
