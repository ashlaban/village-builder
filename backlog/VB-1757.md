- [ ] A controller's command is recorded with its game time (owner sim/controller; plain data, saved); `Sim.command(st, cmd)` is the one door a controller issues through, keyed by its pawn. A run is replayed from a save and the commands recorded since it (the record before a save may be pruned); `tests/decisionpoints.js` replays a scripted controller on a constructed state to the same state.
- [ ] Q13, counted from the points (once, for the PR: populous small seed 7, 2 years, every head given an empty controller that lets the default author answer): points a head-day, an alderman-day and a pawn-day against 1.0, 0.2 and 1.5; the run reaches the same state as with no controllers, but for the controller records.
- [ ] Cost: none in a run with no controller; with one, its pawn's points only.
- [ ] `npm run verify` passes.
