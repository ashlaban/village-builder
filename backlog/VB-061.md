# VB-061: Talk: pawns who meet talk, building ties and opinion
Status: ready
Priority: 2
Size: M
Arch: social
Phase: implement
Design ref: Customs and culture (contacts weighted by time together). Kim, 2026-10-30 (VB-059): the first kind of interaction is talk; interactions happen when pawns meet; a small speech-bubble icon shows over the pair near the camera; talk is not logged as an event.
Goal: Contact hours (`noteContacts`) become interactions. Depends on VB-060; if it is not done, mark this blocked.
Acceptance criteria:
- [ ] Meeting: the pairs `noteContacts` finds each game hour (same house, or outdoors within 30 map units). Outdoor pairs are found by bucketing pawns into map cells of 30 units, not by checking all pairs.
- [ ] Each meeting pair talks at most once per game hour, with chance 0.5 when both are awake and neither is walking with a load. A talk adds 0.1 to the tie (on top of the contact hours) and moves opinion by +0.02 (+0.04 if both are 16–30 and unmarried, which courting builds on later), times (1 − opinion) so it saturates.
- [ ] Each talk is recorded on both agents (`a.talk = { with, until }`, 0.5 game hours) for the page to draw a bubble; the page draws it only for pawns on screen.
- [ ] A talk with someone the pawn likes (opinion ≥ 0.5) adds the mood modifier "talked with a friend" (VB-062), if VB-062 is done.
- [ ] Cost: `tests/perf.js` (or a line in the PR) reports ms per game hour for talk on a populous medium map; target under 5 ms.
- [ ] A test: two pawns placed together talk within a few hours; their opinion rises; it never exceeds 1.
- [ ] Re-record the golden file and list the changed entries in the PR.
