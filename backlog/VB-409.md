# VB-409: Verify's page check and the nightly-only rule checks, rebuilt on small constructed states
Status: ready
Priority: 1
Size: L
Design ref: docs/testing.md (What runs only at night); tests/suites.js
Goal: Verify takes about half a minute (Kim, 13 November: a task's tests are quick; verify is small targeted scenarios, heavily constructed on the super small size; nightly runs the longer tests). The scripts that took over 5 seconds moved to the extended tier as they are, so a task no longer runs the page at all, nor the rules those scripts hold. Each gets a constructed case in verify; the long run stays at night.
Acceptance criteria:
- [ ] The page first: a check in verify, under 5 seconds, that loads the built page in jsdom on the smallest island it can make (or a constructed one), starts a scenario, runs some days and opens the panels; `tests/smoke.js` and the Chromium scripts stay at night.
- [ ] For each script of the second group of `EXTENDED` in `tests/suites.js` (generated islands and runs of years: 47 scripts), the rules it asserts are asserted on a constructed state (`tests/tiny.js`'s `tinyWorld` and `tinyState`, `tests/lib/probe.js`) by a script of `INTEGRATION` under 5 seconds. Where the small case holds everything the long run asserted, the long run is deleted; where the long run shows what a small state cannot (statistics over seeds, generated geography), it stays at night and says so in its first line.
- [ ] Done in groups, a PR each, in this order: the page; saves and the `--extended` variants of `clock`, `spread`, `paths`, `indexes`; the household's rules (`meals`, `stores`, `hunger`, `heirs`, `guardian`, `kinship`, `kinlimit`, `owners`, `plans`, `offers`, `exchange`, `occasions`); the farming year (`newfields`, `weeding`, `soil`, `hay`, `byre`, `herds`, `herding`, `drying`, `forage`, `dig`); land and geography (`rivers`, `stones`, `geology`, `layout`, `settle`, `plots`, `names`); tools (`tools`, `review-tools`, `help`, `bench`, `commands`, `record`, `regress`, `plaindata`, `registry`, `notable`, `manual`).
- [ ] `npm run verify` stays under a minute here and names no script over 5 seconds (`tests/lint.js`, 6 to 7 seconds, is split or sped up); the times before and after are in `docs/testing.md`.
- [ ] No rule is dropped: for each script, the task file lists where each of its assertions went (small case, night, or deleted with the reason).
