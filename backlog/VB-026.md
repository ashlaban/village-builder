# VB-026: Name generators, and farm names in big villages
Status: ready
Priority: 3
Size: M
Arch: expansion
Phase: implement
Design ref: Naming of farms. Not checked tonight.
Goal: Villages of 12-16 farms run out of direction names. VB-021 numbers the extra ones ("Östergården 2"), which is a placeholder. Villages are also named from 88 syllable pairs; a unique name is forced within a map.
Acceptance criteria:
- [ ] A module `src/sim/names.js` (`VB['sim/names']`, `@sys` header, in `src/manifest.json` before `sim/layout`) holds name generators grouped by the kind of thing named: `farm`, `village`, `culture`. Each generator is a function `(ctx, rand) => name | null` (null when it has nothing to offer); `ctx` holds the world, the entity and the names already taken.
- [ ] Farm generators: `compass` (today's direction names, Mellangården included), `landmark` (from the surroundings, as lone farms get today: Strand, Lunden, Backa, Myra, Ängen and the like, extended with more landmark words), `owner` (from the first holder's given name, e.g. "Olofsgården", in the genitive as `patronym` builds it). Village generators: today's syllable names. Culture generators: today's `nameCulture`.
- [ ] A culture holds a preference: an ordered list of generators per kind (`c.namePrefs`, `@state` documented). For now every culture has the same list: farms `compass`, then `landmark`, then `owner`; the first generator that gives a name not already taken in the village wins. A number is added only if all fail.
- [ ] `nameFarms` and the naming of new farmsteads (VB-032) go through the culture's preference; existing names at seeding stay the same where today's rule gives a unique name, so small villages keep their names.
- [ ] A test: a village of 16 farms has 16 distinct names and no numbers at seeds 7 and 42 (populous medium); an `owner` name follows the holder's given name.
- [ ] Re-record the golden file (names in big villages change) and list the changed entries in the PR.
Notes / questions:
- Kim, 2026-10-30: the name generation system has many generators for the different entities; in the long run, cultures prefer different kinds of generators (so names drift and split with cultures). For now, landmarks and owner names are two generators that combine with the existing compass-direction generator.
- Later: cultures that split off (fission) may get a changed preference; people's given names could use the same system.
