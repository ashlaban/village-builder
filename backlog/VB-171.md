# VB-171: The moving round as commands
Status: ready
Priority: 2
Size: M
Arch: core
Phase: implement
Design ref: Commands, time steps and views (Unified commands: Decided); answer 4 to VB-076 (the moving round follows as commands).
Goal: The yearly moving round (`movingRound`, `src/sim/lifecycle.js`) marries couples, moves pawns between households, sends them into service, hands farms on, lets claimants take empty farms and settlers leave, each by calling the function that does it. Make these commands with source `round`, so a player who controls a pawn or a household can later take part in the round on the same terms. Depends on VB-167.
Acceptance criteria:
- [ ] Verbs `marry` (actor and target pawns, args the home household), `move` (a pawn to a household), `serve` (a pawn into service at a household), `handOn` (a holder to an heir, args the reason), `claim` (a pawn claims an empty farm) and `leave` (a party settles new land, args the site): each checks what its function checks today and refuses with a reason otherwise.
- [ ] `movingRound`, `sim/service`, `sim/farmclaims` and `sim/settle` issue them; outside `src/sim/commands.js` nothing calls the functions they wrap, checked statically by the test of VB-167.
- [ ] Behaviour unchanged: `tests/golden.json` unchanged; `npm run verify` passes.
