# VB-307: The menu screens as one family, on a live showcase island
Status: done (2026-11-10)
Priority: 2
Size: M
Design ref: Interface, Saving
Goal: Kim, 10 Nov: the landing page (main menu, New archipelago, the load screen) should be visually cohesive, keeping the main menu's look; the Roadmap, Backlog and Open questions links move to the main menu; the background showcases the game with a super tiny live world.
Acceptance criteria:
- [x] Main menu, New archipelago and Saves use one card: the same width, title and head row, with Back or Close at the title's right; the main menu keeps its look.
- [x] The Roadmap, Backlog and Open questions links stand on the main menu, not on the generation screen.
- [x] Opened from the main menu, Saves is titled Load archipelago, with Back, and takes the menu card's place; in a game it is Saves, with Close.
- [x] With no game open a very small live island plays behind the menu screens; with a game open, the paused game shows.
- [x] The showcase island is no game: no Back to game, no slots to save to, no autosave, no interface over it; it is dropped when a game is generated or loaded.
- [x] The hard checks of `npm run verify` pass, `tests/golden.json` unchanged.
Notes:
- 10 Nov 2026: Kim's answers in the session: a live tiny world (simulated, camera drifting) over a still; the paused game behind the menu when one is open; one Saves overlay, restyled; booked as this task.
- Implementation: `src/page/loader.js` holds `demo` (page state, never in `st`), `buildDemo` (seed 7, 56 by 40 tiles, populous, founders where that finds no room: 7 villages, 21 farms, 133 people) and the two helpers cut out of `build`, `paintOverview` and `swapWorld`, which both builds use. `page/frame` drifts the camera about the largest village; `page/speed` runs the showcase at 3x whole steps; `page/saves` treats it as no game. `build` waits for a showcase still being raised before it swaps its own world in. With `prefers-reduced-motion` the island stands still. A `#hash` start raises no showcase.
- Cost (rule 9): one island of 2,240 tiles, generated in about 30 ms and seeded in about 40 ms (node), and about 20 ms of simulation a game day at 3x (a game day lasts 16 s), only while the menu is up with no game open. Populous does not fit under about 56 by 40 tiles (it asks for more people than the land holds), so this is the smallest island with standing villages.
- Validation: `npm run verify` passes (105 scripts; 6 targets out, none of them moved: the simulation's modules are untouched). `tests/browser-saves.js` checks that the showcase runs behind the main menu, is not offered as a game to go back to or to save, hides the interface, and is gone once a game is open; `tests/smoke.js` checks the links on the main menu. Screenshots at desktop and phone widths were looked at.
- Left as it is: over a paused game the game's own panels show, dimmed, through the menu's veil.
