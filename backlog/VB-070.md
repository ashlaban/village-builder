# VB-070: Lint: no `Math.random` or `Date` in the modules
Status: ready
Priority: 2
Size: S
Arch: tooling
Phase: implement
Design ref: none (CLAUDE.md, Conventions: Determinism).
Goal: Determinism is a convention: all randomness comes from a seeded `mulberry32`, and the modules use no clock. Nothing checks it, and one stray `Math.random` makes every golden and calibration result unreproducible.
Acceptance criteria:
- [ ] `tests/lint.js` fails when a module listed in `src/manifest.json`, or `src/load.js`, contains `Math.random`, `Date.now`, `new Date` or `performance.now`, naming file and line. The page script (`src/body.html`) is exempt, as CLAUDE.md allows.
- [ ] A comment can exempt one line with `// lint-allow: clock` and a reason; there are none today.
- [ ] CLAUDE.md's Determinism line says the lint enforces it.
