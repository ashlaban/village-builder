# VB-088: A performance budget in the verify run
Status: ready
Priority: 3
Size: S
Arch: tooling
Phase: implement
Design ref: Vision and scope (up to about 1,000 pawns); Systems overview (Cost: a budget per system).
Goal: Performance is measured once per task, by hand. A budget checked in the verify run catches the slow step when it is added, not when the page freezes. Depends on VB-052 (`tests/perf.js`); if it is not done, mark this blocked.
Acceptance criteria:
- [ ] `tests/perf.js` runs in `npm run verify` on populous medium at seed 7 for 2 years and reports: ms per game day (mean and worst), and the longest single 6-minute step, meeting and moving round.
- [ ] It fails when the mean exceeds twice the budget (0.5 s of simulation per game day, 10% of real time at 10×), or any single step exceeds twice 50 ms; it prints the budget and the numbers either way.
