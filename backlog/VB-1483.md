# VB-1483: Refactor: Glass is a theme like any other, and the base stylesheet is neutral
Status: done (2026-11-22)
Priority: 2
Size: M
Design ref: Kim, 22 November; VB-1161
Goal: No theme has to undo another: the base stylesheet holds what every theme shares, and Glass's own look sits under its own theme.
Acceptance criteria:
- [x] The root always carries its theme: `data-theme="glass"` is the default, set in the markup and by `applyTheme` (`src/page/options.js`); no theme is "no attribute".
- [x] What is Glass's own look (backdrop blur, soft shadows, translucent panel grounds, hairline borders, the dark palette under `prefers-color-scheme`) sits under `:root[data-theme="glass"]` or in tokens Glass sets; the base stylesheet holds layout and what every theme shares.
- [x] Mural's rules that only undo Glass (`backdrop-filter: none`, `box-shadow: none`, `border: 0`, `background: none` where they cancel a Glass rule; 17 counted on 22 November) are gone, each one or the reason it stays listed in the notes.
- [x] No change of look in either theme: screenshots before and after (Chromium, 1440 by 900; the menu, Options, a game with a household card, a village card and the action bar open; Glass light, Glass dark, Mural), compared by pixel and the differences reported. Screenshots are not committed.
- [x] `tests/page.js` follows (the default is `glass`, not an absent attribute); `npm run verify`, `node tests/page.js` and `node tests/smoke.js` green.
