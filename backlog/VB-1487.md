## Notes

Kim, 22 November. VB-1483 works in the rest of `src/head.html` and in `src/page/options.js` at the same time: keep this task's change to the icons' rules and, in `options.js`, to the one field and the one attribute.

Decisions (VB-1487):
- Markup: each drawing is a `<g data-set="NAME">` in the icon's svg. An icon with no other set keeps its line drawing ungrouped, so every set shows it. `drawings(svg, {set: shapes}, box)` replaces `stencil()`, and an unknown set throws at load.
- CSS: one rule per set other than `line`, which is the fallback: `:root:not([data-icons="S"]) .ico > [data-set="S"], :root[data-icons="S"] .ico:has(> [data-set="S"]) > [data-set="line"] { display: none }`. When the root has no `data-icons`, the line drawing shows, so this works whether or not Glass sets `data-theme`.
- Kept `:root[data-theme="mural"] … { --ico-bg: var(--accent) }`. It sets the mural's ground under a pressed button. That is a theme colour, which the stencil's gaps read; it does not choose a set.
- Look: Playwright screenshots (tiny map, seed 7, paused) of `.hud.top`, `.navigation`, `#actBar`, `#actMenu` (Household) and `#tile` (household card) in both themes. 0 pixels differ except in Glass's `#actMenu`. Its frosted backdrop differs by about as much between two runs taken before the change (184 to 484 of 183,180 pixels).
