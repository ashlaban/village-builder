# VB-143: A profile report: where a game day's time goes
Status: done (2026-11-02, 678365b)
Priority: 2
Size: S
Arch: tooling
Phase: implement
Design ref: Systems overview (Across systems: cost; a budget per system).
Goal: A game day on populous medium costs about 100 ms (`tools/sim.js`, seed 7, years 1-6: 99-127 ms) and the Systems overview quotes 62 ms; the two numbers measure different things and nothing says which system takes the time. A per-system profile makes the next slow step visible and lets VB-088 set a budget per system.
Acceptance criteria:
- [x] `node tools/sim.js --scenario populous --seed 7 --map medium --years 2 --report perf` prints a table: for each system called from `Sim.advance` (jobs refresh and matching, agents and walking, daily life and ties, hunger and meals, herds and byre, meadows, paths, the moving round, meetings) its total ms, ms per game day and share, plus the longest single step.
- [x] Timing is done in the tool by wrapping the `Sim` and `VB[...]` entry points it can reach, not by adding clock calls to `src/` (the lint forbids them); if a system cannot be reached from outside, add a hook that is off by default (`st.profile` absent) and allowed with `// lint-allow: clock`.
- [x] `--json` gives the same table; `AGENTS.md` lists the report; the output does not change the run (the golden file is unchanged, and a run with and without `--report perf` ends in the same state).
- [x] The result is written in the task's notes: the top three systems, and why `tools/sim.js` says about 100 ms a day where `REVIEW.md` says 62 (the moving round's share is the suspect).
Notes / questions:
- Review 1 Nov 2026: animals were measured the same day against the commit before them (`c613a9b`): 95-100 ms/day both ways, so the herds are not the cost; `tests/perf.js` holds the 10 ms budget for them.

The moving round is 2.2 ms/day (117 ms on its one day), so it is not the cause of 100 vs 62: REVIEW.md's 62 ms was measured differently or earlier (not checked here); no per-system budget was set here (VB-088).
