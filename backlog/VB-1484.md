# VB-1484: Refactor: the themes' tokens: fonts, panel, border, shadow and button shape as variables the base uses
Status: ready
Priority: 2
Size: M
Design ref: Kim, 22 November; VB-1161
Goal: A theme is mostly a set of token values: the base stylesheet's literals of colour, radius and font become variables each theme sets.
Acceptance criteria:
- [x] The theme tokens are listed once, in a comment block at the head of the stylesheet, by group: colour, radius, type (heading, body, scroll or label), panel (ground, border, shadow, backdrop), button (ground, border, radius, pressed ground and ink), cast shadow. Every theme sets every one (`--head`, `--scroll`, `--medal`, `--medal-on`, `--cast` are today Mural's alone).
- [x] The base stylesheet uses the tokens: its literals of colour (43 counted on 22 November), of `border-radius` (79) and of font (24) are replaced where a theme would want to change them; those that stay (layout radii, the map's sea, a key's fixed swatch) are counted in the notes with the reason.
- [x] Mural's rules shrink: those that only restate a property a token now carries are removed, and the count of `:root[data-theme="mural"]` rules before and after is in the notes (125 on 22 November). What stays is Mural's own pieces (the band, medallions, beads, black letter where a token cannot say it).
- [x] No change of look in either theme: screenshots before and after as VB-1483 took them, compared by pixel, differences reported.
- [x] `npm run verify`, `node tests/page.js` and `node tests/smoke.js` green.
