# VB-324: The game screen on phones: no title in play, icons for the controls, the speed picker over the notifications
Status: ready
Priority: 2
Size: M
Design ref: Interface; VB-098 (notifications), VB-084 (speeds), VB-307 (menu screens)
Goal: 11 Nov 2026, from a phone: the archipelago's name floats over the map in a row of its own; the Hide UI button is a large text pill that
overlaps the top bar's corner; the speed picker opens under the notifications, which cover it (the toasts' layer, z-index 7, is above the
whole top bar's); and the controls are words where icons would do. The game screen's top bar, dock and panel heads are redone, on phones and,
for the icons, on the desktop too.
Acceptance criteria:
- [x] Batch 1, the top bar. The archipelago's name is not shown in play (phone or desktop); it shows at the top left of the main menu while a
      game is open behind it. Esc, with nothing open to close, opens the main menu; on the main menu with a game open, Esc goes back to it.
- [x] Batch 1. Hide UI is an eye icon at the end of the top bar; with the interface hidden only that eye stays, in the same place, to bring it back.
- [x] Batch 1. The speed picker opens above the notifications; on a phone the notifications start just under the top bar.
- [x] Batch 1. Pause and the speeds are icons, no numbers: pause, then one to five play arrows for 1×, 3×, 10×, 30× and uncapped; each keeps its
      name and key in its tooltip and accessible name; the uncapped speed's measured rate moves to its tooltip.
- [x] Batch 2. The dock's People, Family, Customs, Menu (and Actions) are icons with a short label under each.
- [x] Batch 2. The panel heads' Close is a cross and Collapse/Expand/Details a chevron, with their words kept as accessible names.
- [x] Batch 3. On the desktop too the menu is the dock's: Menu joins the dock and opens the menu panel (layers, notifications, Main menu,
      Saves, Debug) above the dock at its right end; the top-left panel is gone.
- [x] Screenshots before and after, phone (390×844, and landscape) and desktop (1440×900), in `docs/img/vb-324-*` (png for the phone, jpg for the desktop).
- [x] `npm run verify` passes its hard checks; `tests/golden.json` unchanged (no simulation module changes).
