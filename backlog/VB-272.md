# VB-272: The late fixtures as a local cache keyed by the sources, never published
Status: done (2026-11-10)
Priority: 1
Size: M
Arch: yardstick
Phase: implement
Design ref: none (tooling). Kim, 10 November 2026
Goal: The fixtures were stale in every PR of 10 November (a nightly remake against several golden changes a day) and took GitHub storage (a release of about 15 MB and the orphan branch). Made on demand from the sources, none is stale and none is stored.
Acceptance criteria:
- [x] A fixture lies in `tests/fixtures/<key>/`, the key a hash of every module of `src/manifest.json` and of the fixture list; `status` is made or missing, never stale.
- [x] One run a map: `small-y5` is saved on the way to `small-y40`, `medium-y5` on the way to `medium-ref`; a save on the way does not change the run.
- [x] `npm run verify` makes the small pair first when missing, in one lane beside its other scripts; `tests/fixtures.js` checks the small pair and the medium ones where made; `tools/bench.js`, `tools/save-times.js` and `npm run nightly` make what they lack.
- [x] The release code (manifest, fetch, publish, refresh), `.github/workflows/fixtures.yml` and the late-game job of `checks.yml` are removed; `AGENTS.md`, `README.md`, `docs/agents/worker.md` and `docs/roadmap.md` say so.
Notes:
- The release `fixtures` and the orphan branch `fixtures` are still on GitHub: deleting them is VB-225, Kim's.
- 10 Nov 2026, asked by Kim directly ("the fixtures are a nuisance": stale reports, and GitHub storage). Three designs were put: this one, immutable pinned saves loaded through older formats, and a synthesised late state. Kim's decisions: the key is the source hash (sound; a comment under `src/` remakes), medium leaves verify, no scheduled workflow, and comparable history ratios (VB-269: the ratio moves with the state the fixtures hold) are left for later. Older save formats need not load during this phase, which rules out pinned saves.
- Impact: no `src/` change, no state. Reads `src/manifest.json` and its modules (the key). `tests/lib/fixtures.js` and `tools/fixtures.js` rewritten; `tests/run.js` gains chains (the browsers were the one chain; the fixture make and its two scripts are another).
- What fell: the stale state and its notices, the release, manifest, fetch, publish, refresh and rival-publisher handling, a workflow and a workflow job; the three fixture files 383 lines before, 283 after. The stamp keeps the commit for the reader only (`-dirty` when `src/` had changes); the key is the identity.
- `tests/record.js` loses its block on a save from before VB-199 (a copy of each event on its pawn): it ran only on a fixture older than the sources, which no longer exists. Older formats are not promised now (Kim, above).
- A make keeps the newest 3 keys (about 11 MB each with all four saves) and removes the saves of before this task from the top of `tests/fixtures/`.
