# VB-1485: Options: a theme's card previews from the theme's own tokens, and the test counts THEMES
Status: ready
Priority: 2
Size: S
Design ref: Kim, 22 November; VB-1161
Goal: Adding a theme needs no hand-written preview card and no edit to a test's count.
Acceptance criteria:
- [x] A theme's card in Options is drawn from the theme's own tokens: the card's sample carries `data-theme="<key>"` and the theme blocks apply to any element with the attribute (not only `:root`), so the sample shows its theme whatever theme is on.
- [x] The hand-written `.theme-pv.glass` and `.theme-pv.mural` colours are gone from `src/head.html`; a sample is built from the shared pieces (a panel, a head, a pressed and an unpressed button).
- [x] `tests/page.js` counts the themes from `THEMES` (or from the cards drawn), not the literal 2, and walks each: setting it sets the root's attribute and keeps it in localStorage.
- [x] Adding a theme is two edits, an entry in `THEMES` and a token block; the steps are written in `docs/architecture/modules.md`, Adding things.
- [x] `npm run verify`, `node tests/page.js` and `node tests/smoke.js` green.
