Goal: Every act the played pawn has at the moving round is a verb any pawn's controller may issue, under the same check
Acceptance criteria:
- [ ] Two verbs registered at load by the module that carries the act out (`register(verb, {check, run})` of sim/commands): `wish` (kind, value: a pawn's own wish at the round, `pawn.wish`) and `propose` (a spokesman's match for a member, `pawn.proposal`); each check reads the actor's position (alive, the member's spokesman), never whether it is played, and returns why not, with the reasons `Sim.wish` gives today.
- [ ] `Sim.wish` issues the verb for the played pawn (source `player`), so the page's callers are unchanged; a pawn's own logic or another controller issues it with source `pawn`.
- [ ] `tests/commands.js`: `wish` and `propose` issued for an unplayed pawn set its wish and its proposal as for the played one; a refused one changes nothing; the round reads them alike (`tests/wishes.js`).
- [ ] `npm run verify` passes; unplayed runs are unchanged (`node tools/same.js --base REF` prints `same`).
