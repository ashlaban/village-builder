# VB-1489: Refactor: the themes' tokens as scales: one of radii, one of shadows, and the quirk tokens gone
Status: ready
Priority: 2
Size: M
Design ref: Kim, 23 November; VB-1484
Goal: A theme sets fewer tokens, each with a plain meaning; corners and shadows snap to a scale.
Acceptance criteria:
- [ ] One radius scale (`--r-0` none, `--r-1` small, `--r-2` large, and round), replacing `--r-panel`, `--r-small`, `--r-field`, `--r-row`, `--r-meter`, `--r-portrait`, `--r-tag` and `--btn-radius`; each use takes a step of the scale. One shadow scale (resting, raised, floating) replacing `--panel-shadow`, `--panel-rise`, `--cast` and `--float`.
- [ ] The tokens that encode one theme's quirk go, each either folded into that theme's styling of a piece (VB-1488) or dropped: `--panel-side`, `--head-style`, `--medal`, `--medal-on`, and any other no second theme would set differently for a reason. The list at the head of the stylesheet is 28 tokens or fewer (40 today), the count before and after in the notes with what each removed token became.
- [ ] Every theme sets every token, and `tests/themes.js` passes unchanged in its rules.
- [ ] The look may change, and Kim judges it: screenshots before and after as VB-1488 took them, saved outside the repository at the path the result names; the notes list each change a person would notice.
- [ ] `docs/architecture/modules.md`, Adding things, follows. `npm run verify`, `node tests/page.js`, `node tests/smoke.js` and the browser tests the change touches green.
