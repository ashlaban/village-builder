# Village builder

A village builder on a generated hex archipelago, in one self-contained HTML page (PixiJS 8).

- **Play online:** <https://ashlaban.github.io/village-builder/>
- **Play locally:** open `index.html` in a browser.
- **Build:** `python3 build.py` inlines `src/` into `index.html`.
- **Test:** `npm install && npm test` (headless simulation and page smoke tests, Node 20+).
